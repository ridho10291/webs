Saya ingin membuat website Portofolio Personal yang persis mirip secara gaya visual dan struktur dengan web https://www.syahrilarfianalmazril.my.id/ untuk dipamerkan dalam portofolio saya.

Teknologi yang digunakan: React.js (Vite) + Tailwind CSS + Lucide Icons + Framer Motion (untuk animasi halus).

Tolong kerjakan dengan pendekatan 2 Tahap (Plan dulu, baru Build):

=== TAHAP 1: PLANNING (JANGAN TULIS KODE DULU) ===
Buatkan perencanaan presisi yang mencakup:
1. Break-down Layout & Komponen Visual:
   - Hero / Header Section (Foto Profil, Nama, Peran/Role, Status Badge "Available for Work").
   - Bento Grid Layout (Susunan kartu About Me, Tech Stack, Featured Projects, Kontak, dan Link Medsos).
   - Component Card (Desain border halus, efek hover glow/elevasi, dan latar belakang glassmorphism/dark card).
2. Skema Warna & Styling:
   - Palette warna Dark Mode yang persis (Background, Card Color, Text Primary/Secondary, Accent Color).
   - Font family dan penataan hierarki teks.
3. Arsitektur Data & Props:
   - Struktur JSON lokal untuk Data Profil, List Projects (Judul, Deskripsi, Tech Used, Live Demo Link, GitHub Link), dan List Tech Stack (Icon name + Label).
4. Animasi & Interaktivitas:
   - Daftar animasi micro-interaction menggunakan Framer Motion (Fade in pada scroll, hover scale pada card).

Tanyakan kepada saya apakah perencanaan Tahap 1 ini sudah mirip dan sesuai keinginan sebelum kita masuk ke penulisan kode.

=== TAHAP 2: BUILDING (SETELAH SAYA SETUJU) ===
Setelah saya memberi konfirmasi "SETUJU", baru kamu menuliskan kode lengkap:
1. Setup Tailwind & Konfigurasi warna khusus.
2. File Data Dummy (portfolioData.js).
3. Komponen-komponen modular (HeroCard, ProjectCard, TechStackCard, SocialLinks, Footer).
4. Code App.jsx lengkap dengan tata letak Bento Grid yang responsif (Mobile ke Desktop).

Sekarang, tolong fokus sajikan TAHAP 1 (PLANNING) terlebih dahulu!
