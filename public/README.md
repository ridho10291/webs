# Folder Asset Gambar & Media Statis (`/public`)

Anda dapat meletakkan seluruh foto lokal Anda di folder ini:
- `public/profile.jpg` -> Akses di kode dengan `"/profile.jpg"`
- `public/profile-hover.jpg` -> Akses di kode dengan `"/profile-hover.jpg"`
- `public/projects/project1.png` -> Akses di kode dengan `"/projects/project1.png"`
- `public/certificates/cert1.png` -> Akses di kode dengan `"/certificates/cert1.png"`

Semua file yang berada di dalam folder `/public` dapat langsung diakses dari browser dengan format path relatif berawalan garis miring `/`.
